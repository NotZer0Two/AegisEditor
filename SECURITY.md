# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a vulnerability, **do not** report it through a public GitHub issue, pull request, or Discord.

### How to Report

Use GitHub Private Vulnerability Reporting via the [Security Advisories](../../security/advisories/new) tab of this repository.

Please include as much of the following as possible:
- Type of vulnerability
- Step-by-step instructions to reproduce it
- Proof-of-concept (if available)
- Potential impact

### What to Expect

- We will acknowledge your report within 5-7 days.
- We will keep you updated on progress and let you know when the issue is fixed.
- We will credit you in the advisory if you wish.

### Supported Versions

Only the latest release and the `main` branch receive security fixes.

### Guidelines

We ask that you:
- Give us a reasonable amount of time to fix the issue before public disclosure.
- Avoid accessing or modifying data that does not belong to you.
- Act in good faith and avoid actions that could harm the project or its users.
