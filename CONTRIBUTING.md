# Contributing to the editor

Thanks for taking the time to contribute. I'm glad you're here.

## Before you start

- For small fixes (typos, obvious bugs, small refactors), open a PR directly.
- For larger changes, open an issue first or ask on the Discord linked in the [README](./README.md).
- Report security vulnerabilities privately; see [SECURITY.md](./SECURITY.md). Do not use public issues or PRs.
- Keep each PR focused on a single topic.
- PRs that are low quality or don't follow the repo's conventions may be rejected.
- Don't use the LabAPI or Assembly-CSharp references inside the API those should be used only in the Plugin

## AI / LLM usage

AI tools (e.g. ChatGPT, Claude, Copilot, Cursor) are allowed, but:

- Disclose AI usage in the PR.
- PRs that are mostly AI-generated may be rejected.
- Commit messages and PR descriptions, including how the code works, must be written by you.
- Maintainers may ask questions about your contribution, or decline it, if AI usage is suspected and you can't explain the code.

## Review

- A maintainer will review your PR. Expect change requests on the first pass for larger contributions.
- Keep your PR up to date with `main`. Rebase instead of merging.
